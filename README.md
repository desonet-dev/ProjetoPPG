# ProjetoPPG

Site construído em parceria com a Etec de Taboão da Serra, a fim de aprimorar a gestão de chamados e ocorrências técnicas cotidianos no ambiente escolar.

# Tecnologias utilizadas

* **React:** Biblioteca utilizada para construir a interface da página web.
* **Firebase (Firestore e Authentication):** Plataforma utilizada para a autenticação segura de usuários e para o armazenamento e sincronização dos chamados em tempo real.

# Principais funcionalidades

* **Abertura de Chamados:** Permite que professores e funcionários relatem problemas técnicos em salas de aula ou laboratórios.
* **Painel do Técnico:** Tela exclusiva para a equipe de TI visualizar, triar, alterar o status e encerrar as ocorrências pendentes.
* **Acompanhamento em Tempo Real:** Atualização instantânea do progresso dos chamados graças à integração nativa com o Firestore.
* **Histórico de Ocorrências:** Registro completo de todos os eventos finalizados para fins de auditoria e métricas de manutenção.
